# Initial planning prompt

- PHP, Laravel app with FilamentPHP, PostgresSQL database. All with their latest versions as of 2026-05-27
- end goal is to have a Docker container that can be run in an Unraid OS server
- mobile device usage focus to make it easy to use on smaller devices (for example during maintenance work)
- translation and i18n support from the start to make it more accessible
